# Project: TrailMarker - Front End

## Stack

- React, Typescript, Tanstack Query, Tanstack Router, Mantine, Leaflet, React Hook Form
- Connects to a Laravel Sanctum API

## General Instructions

- Imports should always be organized in their dedicated section which is declared by a comment like // Utils or // Queries
- Use the latest features of the installed version of React

## Coding Style

- Airbnb Javascript / Typescript Style Guide
